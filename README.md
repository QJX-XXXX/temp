## 修改说明

`saltline.html` 在原版基础上做了一处修改：开镜改为轻点右键切换，也可以按键盘上的 Z 键切换。这样可以避免“按住右键拖动”触发浏览器的鼠标手势、导致游戏暂停。在设置里关闭 Toggle aim (tap right button) 开关后，即恢复原版的按住右键开镜。

其余两个文件与原版一致，未做修改。
